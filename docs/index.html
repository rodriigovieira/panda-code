Panda Code

Run Claude Code and Codex as persistent threaded sessions on your Mac. Keep long jobs alive, review structured output, and optionally pair a phone through a relay you host yourself.

Build from source View repository
Local by default No account, hosted API, or project upload in desktop mode.
Two runtimes Claude Code and Codex run as external CLIs you control.
Self-hosted phone Optional Convex relay carries ciphertext plus routing metadata.

Built for sessions that keep moving.

Panda Code turns agent work into a persistent workspace instead of a pile of terminal windows. The app tracks state, cost, and attention without taking ownership of your code or credentials.

01

Threaded sections

Run multiple agent threads side by side and return to the one that needs input.

Runtime controls

Usage visibility

See token and cost totals by session and over time while the work is still active.

Optional companion

Use your phone without trusting someone else's server.

The mobile app pairs with your Mac through a Convex deployment you own. Content fields are encrypted before they touch the relay; the relay only keeps the metadata it needs to route updates.

Create your relay

Deploy the Convex functions under your own account and keep the URL in your local config.

Pair with a QR code

The QR payload carries the one-time pairing code and the shared encryption key.

Approve from anywhere

Review waiting sessions, send follow-ups, and approve or deny requested actions.
